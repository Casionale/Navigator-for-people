# План разработки Web-версии "Помойка"

## Оценка текущей программы

### Общая характеристика
Приложение "Помойка" — это инструмент автоматизации административных задач для системы
навигации/записи детей в учреждении ДП29 (booking.dop29.ru). Проект прошёл 3 стадии развития:

| Стадия | Файлы | Интерфейс | Статус |
|--------|-------|-----------|--------|
| 1. Процедурный скрипт | `pomoika.py` | `input()` в консоли | Устарел |
| 2. TUI (терминальный) | `menu.py` + `forms.py` + `application.py` | npyscreen/curses | Рабочий |
| 3. GUI (десктопный) | `refactored_pomoika.py` + `PomoikaUtils.py` + `.ui` | PyQt5 | Рабочий (частично) |

### Сильные стороны
- Полная автоматизация основных задач (зачисление, посещаемость, статистика, документы)
- Наличие OOP-рефакторинга (`App` в `application.py`, `NavigatorClient` в `PomoikaUtils.py`)
- Генерация Word-документов (диагностические карты)
- Интеграция с Яндекс.Диском для скачивания файлов
- Генерация сертификатов (отдельный модуль `gensert.py`)

### Слабые стороны
- `requirements.txt` пуст — зависимости не зафиксированы
- Нет обработки ошибок API (try/except минимальны)
- Дублирование кода между `pomoika.py` и `application.py` (одна и та же логика twice)
- Магические числа и хардкод URL/параметров
- Нет тестов
- `login.ini` с открытыми кредами в репозитории
- `main.html` — посторонний файл (админка роутера), не относится к проекту
- PyQt5 GUI загружает `.ui` файл из текущей директории (ломается при запуске не из корня)

## Описание Web-версии

### Концепция
Веб-интерфейс для работы с локальными данными БЕЗ прямых вызовов API.
Приложение будет:
- Загружать и обрабатывать Excel/CSV файлы с данными
- Генерировать отчёты (HTML/PDF/DOCX) из загруженных данных
- Предоставлять визуальную статистику (графики, таблицы)
- Работать в браузере без установки

**API к booking.dop29.ru НЕ вызывается** — вместо этого данные загружаются
из файлов (Excel, CSV, JSON) или из предварительно сохранённых дампов.

### Стек технологий
| Компонент | Технология | Обоснование |
|-----------|-----------|-------------|
| Backend | **Flask** | Лёгкий, простой, уже есть шаблонизатор Jinja2 в проекте |
| Frontend | **Bootstrap 5 + Chart.js** | Быстрый UI без сборки, графики из коробки |
| Шаблоны | **Jinja2** | Уже используется в проекте (`templates/template.html`) |
| Обработка данных | **pandas** | Уже используется в проекте |
| Генерация документов | **python-docx** | Уже используется в проекте |
| PDF | **pdfkit + wkhtmltopdf** | Уже есть бинарник в проекте |

### Функции Web-версии (БЕЗ API)
1. **Загрузка данных** — импорт Excel/CSV файлов с информацией о детях, группах, посещаемости
2. **Просмотр групп и детей** — таблицы с фильтрацией и сортировкой
3. **Статистика по возрастам** — графики распределения по возрасту/полу
4. **Генерация отчётов** — HTML/PDF таблицы посещаемости (на основе `templates/template.html`)
5. **Поиск дубликатов** — поиск детей, повторяющихся в нескольких группах (из загруженных данных)
6. **Поиск проблемных групп** — группы с малым количеством детей
7. **Экспорт в DOCX** — генерация диагностических карт (из загруженных данных)
8. **Панель управления** — дашборд с ключевыми метриками
