# 17.09.2026 — Релиз 1.0.3-beta: принудительная заявка детей в группу (админ)
- Новое окно «Принудительная заявка детей в группу» (кнопки на главной и на странице «Заявки»).
- Ввод списка вручную (строки «ФИО<TAB>фрагмент программы») или загрузка .txt, как в pomoika.py.
- Интерактивный поиск ребёнка по ФИО с выбором из найденных, выбор группы для каждой строки.
- Поиск по группам внутри окна: фильтр по названию группы/программы (список из сотен групп).
- Общий селектор группы по умолчанию + своя группа на каждую строку.
- Мини-модалка «Войти как администратор»: отдельный клиент навигатора только для админ-действий, обычный интерфейс работает под прежним аккаунтом.
- Поиск детей (в том числе кнопка «🔍 Поиск» в навбаре) тоже работает через админ-аккаунт.
- Действия помечены значком 🔐 админ (поиск и создание заявок требуют прав администратора).

# 14.09.2026 — Релиз 1.0.2-beta: посещаемость на клик
- Клик по ячейке ученика — проставить/снять посещаемость (toggle).
- Клик по шапке дня — проставить/снять ✓ всем ученикам за дату.
- Исправлена вместимость групп: теперь берётся из размера группы (`size`), а не из программы.
- Исправлен формат значений посещаемости: API принимает `true`/`false` вместо чисел.
- Счётчик заявок: запрос выполняется сразу при загрузке/логине, вкладка «Заявки» принудительно синхронизирует счётчик.
- Текущая версия отображается в навбаре (единый источник — файл `VERSION`).

# 02.09.2026 — Веб-версия 1.0-beta
Переезд с консольной на веб-версию.
Доступ: https://nav.bakasenpai.ru

Что сразу работает:
- Вход по email/паролю навигатора, учебные годы.
- Главная: программы и группы, поиск ребёнка, 7 тем оформления.
- Страница группы: посещаемость, КТП, заявки, расписание, переименование группы.
- Отчёты: по возрастам, по программам, проблемные группы (до 10 человек), дубликаты детей.
- Контакты детей с копированием для Excel.

Примечание: бета. Данные читаются без изменений, кроме расписания и переименования групп — там подтверждение через модальное окно.
