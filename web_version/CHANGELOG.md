# 14.09.2026 — Посещаемость: клик по ячейке и шапке дня
- Клик по ячейке ученика — проставить/снять посещаемость (toggle).
- Клик по шапке дня — проставить/снять ✓ всем ученикам за дату.
- Исправлена вместимость групп: теперь берётся из размера группы (`size`), а не из программы.
- Исправлен формат значений посещаемости: API принимает `true`/`false` вместо чисел.
- Счётчик заявок: запрос выполняется сразу при загрузке/логине, вкладка «Заявки» принудительно синхронизирует счётчик.
